# cutfps

スマホで撮った動画（特に落下する小さなボールなど）から、動体だけを抜き出して1枚のストロボ写真に合成する Web アプリです。

処理はすべて端末内の Canvas で行い、動画をサーバーに送りません。

## 機能

- 動画ファイルの選択（スマホのギャラリー / 撮影アプリから）
- 合成モード
  - **ボール軌跡（デフォルト）**: 背景との差分で動体だけを重ねる
  - **クラシック**: `lighten` で明るい部分を重ねる
  - **半透明**: 各フレームを等分アルファで重ねる
- 落下区間の自動検出、ボールの拾いやすさ調整
- **元fps 基準の間引き**（例: 240fps × 15fps → 16 フレームごとに 1 枚）
- 間引き密度（1 / 5 / 10 / 15 / 30）と元 fps（30 / 60 / 120 / 240）
- MP4/MOV からの元 fps 自動検出（失敗時は手動指定、デフォルト 240）
- 開始・終了秒の指定
- 進捗表示・キャンセル
- PNG 保存 / Web Share API による共有

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開き、動画を選んで「ストロボ写真をつくる」を押します。

本番ビルド:

```bash
npm run build
npm run preview
```

## 技術

- Vite + React + TypeScript
- Tailwind CSS v4
- ブラウザ API: `<video>` seek + Canvas 2D
- mp4box（元 fps 検出）

## 制約

- 長尺動画は最大 60 フレームで打ち切り
- 長辺は最大 1280px にダウンサンプル
- 端末・コーデックによっては読み込みに失敗することがあります（MP4 / H.264 推奨）
